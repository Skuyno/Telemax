## 2026-09-18 — Локальное окружение

Всё ниже — локальные файлы, в гит не попадают (`.env` и `docker-compose*.yml` в `.gitignore`).

- Созданы все `.env` по образцу `.env.example`: `deploy/.env`, `src/services/{identity,communication,api-gateway,ws-gateway}/.env`, `src/web/.env`.
  - `JWT_SECRET` одинаковый в `identity`, `api-gateway`, `ws-gateway` — иначе токен молча не проходит валидацию.
  - `POSTGRES_DB`: `telemax_identity` / `telemax_communication` — ровно те базы, что создаёт `deploy/initdb/01-databases.sql`.
- `deploy/docker-compose-local.yml` — на хосте заняты `8000` и `5432`:
  - `api-gateway`: `8080:8000`, `db`: `5433:5432`; `NUXT_PUBLIC_API_BASE` в `.env` фронта → `http://localhost:8080`.
  - **Важно:** для `api-gateway` нужен `ports: !override`. Без него compose **склеивает** списки портов с базовым файлом, `8000:8000` остаётся и контейнер падает на занятом порту.
- Запуск: `docker compose -f docker-compose.yml -f docker-compose-local.yml up -d --build` из `deploy/`. Для вёрстки удобнее погасить контейнер `web` и запускать фронт через `npm run dev` в `src/web/` (hot-reload).

## 2026-09-18 — Страница личных чатов

По макету «Личные чаты» (та же палитра, что у «Входа»; Unbounded / Space Grotesk / IBM Plex Mono, острые углы, жёсткие тени).

- **`app/pages/index.vue`** — главная теперь = экран чатов. Заготовка-полотно перезаписана.
  - `definePageMeta({ layout: false })`: по макету общей шапки нет — логотип в шапке списка, справа своя шапка диалога. `layouts/default.vue` не тронут, на нём остаётся `/settings`.
  - Две колонки (список 300px + диалог); на `<900px` — одна колонка, в диалоге появляется кнопка «назад».
- **`app/components/chat/`** — новые компоненты:
  - `Sidebar.vue` — логотип + акцентная линия 2px, шестерёнка настроек (переехала из общей шапки), поиск, список.
  - `ListItem.vue` — строка чата: квадратный аватар с инициалами, имя, превью «Вы: …», время; hover и активное состояние (левая рамка 2px accent).
  - `Dialog.vue` — шапка с именем, лента с разделителями дат, поле ввода + кнопка «Отправить» (Enter тоже отправляет).
  - `Message.vue` — входящий/исходящий пузырь со временем.
  - `Empty.vue` — «Чатов пока нет» / «Выберите чат».
- **`app/utils/chatTime.ts`** — время в списке (`20:54` / `вчера` / `пн` / `ДД.ММ`), время в пузыре, разделители «Сегодня / Вчера / 18 сентября».
- **`app/types/chat.ts`** — типы один в один с ответами `communication`: `Chat { id, title, initials, lastMessage }`, `Message { id, chatId, senderId, body, createdAt }`.
- **`app/stores/chat.ts`** — стор пустой по умолчанию; `meId` берётся из `authStore.user.id`; `visibleChats` (локальный поиск по названию), `setChats` / `setMessages` / `sendMessage` (пока только локально). В шапке файла — комментарий с маппингом на эндпоинты для будущего подключения.

## Правила, установленные пользователем по ходу работы

- Работаем только над фронтендом (`src/web/`); бэкенд — только для изучения контрактов API, не редактируем без явного разового разрешения.
- Не добавлять/обновлять npm-зависимости без необходимости и согласования.
- **Не вводить новые цвета** — только существующие токены из `app/assets/styles/colors.css`. Если подходящего нет — заменить на существующий, а не добавлять свой.
- **Не показывать в UI то, чего нет на бэкенде**, и не использовать выдуманные данные.
- После крупных изменений — вести и дополнять этот файл (`BACKLOG-ksenia.md`).
